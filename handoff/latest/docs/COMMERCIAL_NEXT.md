# 下一步商业验证建议

当前没有商业胜出者。先让Human在统一入口对三款各体验十局，再看是否愿意主动多玩；所有候选均可淘汰。自动化完成十局只证明循环能运行。

试玩时先试特色规则，再切普通规则用同一局面比较；第二位试玩者可反过来，减少先后顺序影响。观察：是否不用口头教程就能完成第一步、无效操作是否频繁、失败是否能解释、是否主动点重试、十局以后是否还想玩、特色规则有没有改变决策而非增加麻烦。页面可在本机保存判断并导出JSON，没有远程收集。

建议内部筛选标准（**项目提案，不是行业基准**）：首步能独立完成；多数试玩者可清楚说出失败原因；至少一款让Human主动完成十局且愿意继续。小样本只能淘汰明显问题，不能证明留存/盈利。不用机器人胜率、测试耗时或研究者喜好代替Human判断。

若有通过者，先补真机与TapTap H5宿主适配，再做小范围原型对照验证。只有Human确认立项后才安排正式美术、更多关卡和广告接入。若全部不通过，回看解堵/区域逻辑候选，不继续靠皮肤、成长、签到挽救现有原型。

IAA仅规划：摆块可考虑一次可选救场；排序可考虑额外可选提示，不能破坏本轮已证明的免费可解路径；拆塔仅弹药不足时可选续弹，保护核心失败需要重开才能保持规则可信。当前没有任何广告代码或模拟广告按钮。
